## Formato de Respostas

Todas as respostas da API utilizam codificação `application/json; charset=utf-8`.

### Códigos de Retorno Padronizados

| Código | Significado | Descrição |
| :--- | :--- | :--- |
| `200 OK` | Sucesso | A requisição foi atendida com êxito. |
| `201 Created` | Criado | Novo recurso instanciado (usuário, sala, mensagem, report, feedback). |
| `400 Bad Request` | Requisição Inválida | Campos obrigatórios ausentes ou valores com tipos incorretos. |
| `401 Unauthorized` | Não Autorizado | Token JWT ausente, corrompido ou expirado. |
| `403 Forbidden` | Proibido | O usuário autenticado não possui privilégios para executar a ação. |
| `404 Not Found` | Não Encontrado | O ID do recurso pesquisado não existe no banco. |
| `409 Conflict` | Conflito | Tentativa de registrar e-mail que já existe. |
| `500 Server Error` | Erro Interno | Falha inesperada durante a execução no servidor. |
