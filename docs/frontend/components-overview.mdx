## Tabela de Componentes Principais

| Componente | Caminho do Arquivo | Propósito Principal |
| :--- | :--- | :--- |
| `<UserAvatar />` | `src/components/UserAvatar.jsx` | Exibe imagem de perfil ou iniciais com moldura gradiente e anéis de presença online/offline. |
| `<SkeuoLoading />` | `src/components/SkeuoLoading.jsx` | Tela e indicador de progresso com animação de shimmer e barra física preenchida. |
| `<SkyBackground />`| `src/components/SkyBackground.jsx` | Fundo de céu atmosférico animado que se adapta ao tema e paleta de cores ativa. |
| `<Navbar />` | `src/components/Navbar.jsx` | Barra superior com controle de modo escuro, seleção de cores, perfil e logout. |
| `<ChatSidebar />` | `src/components/ChatSidebar.jsx` | Menu lateral com lista de canais disponíveis e botão de criar sala. |
| `<MembersSidebar />`| `src/components/MembersSidebar.jsx`| Lista lateral de membros da sala com separação por papéis (`Dono`, `Admin`, `Membro`). |
| `<PrivateRoute />` | `src/components/PrivateRoute.jsx` | Guarda de rota que redireciona usuários não autenticados para `/login`. |
| `<AdminRoute />` | `src/components/AdminRoute.jsx` | Guarda de rota que valida privilégios de administrador antes de abrir `/admin`. |

## Classes de Apoio do Design System

Além dos componentes em arquivos `.jsx`, a interface utiliza classes utilitárias semânticas declaradas em `src/styles/skeuo.css` e `src/styles/skeuo-extra.css`:

### Badges e Indicadores de Estado (`.skeuo-badge-*`)
- `.skeuo-badge-online`: Indicador verde esmeralda para usuários ativos.
- `.skeuo-badge-ativa`: Indicador azul para salas com conversas em andamento.
- `.skeuo-badge-dono`: Marcador dourado/âmbar exclusivo para o criador da sala.
- `.skeuo-badge-admin`: Marcador violeta para operadores com permissões elevadas.
- `.skeuo-badge-mod`: Marcador ciano para moderadores de canal.

### Efeitos de Superfície
- `.skeuo-surface-orb-badge`: Círculo com relevo central utilizado em ícones e contadores numéricos.
- `.skeuo-well`: Recesso de luz invertida que dá a sensação de área afundada na tela.
