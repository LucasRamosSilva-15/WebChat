| Componente | Caminho do Arquivo | Propósito Principal |

## Classes de Apoio do Design System

Além dos componentes em arquivos `.jsx`, a interface utiliza classes utilitárias semânticas declaradas em `src/styles/skeuo.css` e `src/styles/skeuo-extra.css`:

### Badges e Indicadores de Estado (`.skeuo-badge-*`)
- `.skeuo-badge-online`: Indicador verde esmeralda para usuários ativos.
- `.skeuo-badge-ativa`: Indicador azul para salas com conversas em andamento.
- `.skeuo-badge-dono`: Marcador dourado/âmbar exclusivo para o criador da sala.
- `.skeuo-badge-admin`: Marcador violeta para operadores com permissões elevadas.
- `.skeuo-badge-mod`: Marcador ciano para moderadores de canal.

### Efeitos de Superfície
- `.skeuo-surface-orb-badge`: Círculo com relevo central utilizado em ícones e contadores numéricos.
- `.skeuo-well`: Recesso de luz invertida que dá a sensação de área afundada na tela.
