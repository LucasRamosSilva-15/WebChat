Este guia orienta você na realização do fluxo completo de ponta a ponta na API WebChat: registro de conta, autenticação, criação de uma sala e envio de mensagem.

<Steps>
  <Step title="1. Registrar um Novo Usuário">
    Envie uma requisição `POST` para o endpoint `/auth/register`. A senha fornecida será automaticamente criptografada via `bcrypt` no backend antes de ser salva no banco PostgreSQL.

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://webchat-9vqr.onrender.com/api/auth/register" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Dev Antigravity",
        "email": "dev.antigravity@example.com",
        "password": "SenhaSegura@2026"
      }'
    ```

    ```javascript Node.js (Fetch)
    const response = await fetch('https://webchat-9vqr.onrender.com/api/auth/register', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        name: 'Dev Antigravity',
        email: 'dev.antigravity@example.com',
        password: 'SenhaSegura@2026'
      })
    });

    const data = await response.json();
    console.log('Token recebido:', data.token);
    ```

    ```python Python (Requests)
    import requests

    url = "https://webchat-9vqr.onrender.com/api/auth/register"
    payload = {
        "name": "Dev Antigravity",
        "email": "dev.antigravity@example.com",
        "password": "SenhaSegura@2026"
    }

    res = requests.post(url, json=payload)
    data = res.json()
    token = data.get("token")
    print(f"Token JWT: {token}")
    ```
    </CodeGroup>

    #### Estrutura de Retorno (201 Created)

    <ResponseField name="user" type="object" required>
      Objeto com os dados públicos do usuário recém-criado.
      <Expandable title="propriedades de user">
        <ResponseField name="id" type="string (UUID)">Identificador único gerado pelo banco.</ResponseField>
        <ResponseField name="email" type="string">E-mail único de acesso.</ResponseField>
        <ResponseField name="displayName" type="string">Nome público exibido no chat.</ResponseField>
        <ResponseField name="name" type="string">Nome de compatibilidade com o frontend.</ResponseField>
        <ResponseField name="created_at" type="string">Timestamp ISO 8601 da criação.</ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="token" type="string" required>
      Token JWT assinado pelo algoritmo HS256 com validade de 7 dias.
    </ResponseField>
  </Step>

  <Step title="2. Criar uma Nova Sala de Conversa">
    Com o token obtido, faça uma requisição autenticada para `POST /rooms`. O usuário que cria a sala é associado automaticamente como proprietário (`owner`) inicial.

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://webchat-9vqr.onrender.com/api/rooms" \
      -H "Authorization: Bearer <SEU_TOKEN_JWT>" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Sala de Integração API",
        "description": "Canal dedicado a testar webhooks e automações",
        "type": "public",
        "category": "engenharia"
      }'
    ```

    ```javascript Node.js
    const roomResponse = await fetch('https://webchat-9vqr.onrender.com/api/rooms', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        name: 'Sala de Integração API',
        description: 'Canal dedicado a testar webhooks e automações',
        type: 'public',
        category: 'engenharia'
      })
    });

    const room = await roomResponse.json();
    console.log('ID da Sala:', room.id);
    ```

    ```python Python
    headers = {"Authorization": f"Bearer {token}"}
    room_payload = {
        "name": "Sala de Integração API",
        "description": "Canal dedicado a testar webhooks e automações",
        "type": "public",
        "category": "engenharia"
    }

    room_res = requests.post(
        "https://webchat-9vqr.onrender.com/api/rooms",
        headers=headers,
        json=room_payload
    )
    room = room_res.json()
    room_id = room["id"]
    print(f"Sala criada com ID: {room_id}")
    ```
    </CodeGroup>
  </Step>

  <Step title="3. Enviar a Primeira Mensagem">
    Agora, envie uma mensagem de texto e/ou com anexo de imagem utilizando o `id` da sala criada no caminho `/rooms/{roomId}/messages`:

    <CodeGroup>
    ```bash cURL
    curl -X POST "https://webchat-9vqr.onrender.com/api/rooms/<ROOM_ID>/messages" \
      -H "Authorization: Bearer <SEU_TOKEN_JWT>" \
      -H "Content-Type: application/json" \
      -d '{
        "content": "Olá a todos! Primeira mensagem enviada com sucesso via API.",
        "imageUrl": "https://storage.webchat.com/uploads/diagram.png"
      }'
    ```

    ```javascript Node.js
    const msgResponse = await fetch(`https://webchat-9vqr.onrender.com/api/rooms/${room.id}/messages`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        content: 'Olá a todos! Primeira mensagem enviada com sucesso via API.',
        imageUrl: 'https://storage.webchat.com/uploads/diagram.png'
      })
    });

    const message = await msgResponse.json();
    console.log('Mensagem gravada:', message.id);
    ```

    ```python Python
    msg_payload = {
        "content": "Olá a todos! Primeira mensagem enviada com sucesso via API.",
        "imageUrl": "https://storage.webchat.com/uploads/diagram.png"
    }

    msg_res = requests.post(
        f"https://webchat-9vqr.onrender.com/api/rooms/{room_id}/messages",
        headers=headers,
        json=msg_payload
    )
    print("Resposta do Envio:", msg_res.json())
    ```
    </CodeGroup>
  </Step>

  <Step title="4. Buscar Histórico de Mensagens">
    Recupere as mensagens da sala ou faça buscas por palavra-chave utilizando o endpoint `/rooms/{roomId}/messages/search?q=termo`:

    <CodeGroup>
    ```bash cURL
    curl -X GET "https://webchat-9vqr.onrender.com/api/rooms/<ROOM_ID>/messages/search?q=Primeira" \
      -H "Authorization: Bearer <SEU_TOKEN_JWT>"
    ```

    ```javascript Node.js
    const searchRes = await fetch(`https://webchat-9vqr.onrender.com/api/rooms/${room.id}/messages/search?q=Primeira`, {
      headers: { 'Authorization': `Bearer ${token}` }
    });
    const results = await searchRes.json();
    console.log(`Encontradas ${results.length} mensagens.`);
    ```

    ```python Python
    search_res = requests.get(
        f"https://webchat-9vqr.onrender.com/api/rooms/{room_id}/messages/search?q=Primeira",
        headers=headers
    )
    print("Resultados da Busca:", search_res.json())
    ```
    </CodeGroup>
  </Step>
</Steps>
